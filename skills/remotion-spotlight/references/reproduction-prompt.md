# 復現提示詞

先檢視此 repo 的 [聚光燈參考動畫](../../../previews/spotlight.gif)，再在目前專案中重現它的引導觀看方式。不要複製範例畫面的狀態卡、文字、配色或版面；請使用目前專案中需要觀眾注意的真實元件。

將介面其餘區域壓暗，並以圓角挖空區依序框選一到三個有意義的 UI 目標。停留與移動時長應從目前場景的敘事節奏推導，而不是硬套參考影片格數。挖空區必須緊貼目標並始終位於可見內容上：絕不可落在空白區、遮住目標、或形成不透明白色彈窗。若場景有縮放、裁切或移動，讓聚光燈與相同 transform origin、縮放比同步。完成後檢查每個重點在壓暗畫面中仍清晰可讀。
