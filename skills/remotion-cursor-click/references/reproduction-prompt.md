# 復現提示詞

先檢視此 repo 的 [游標點擊參考動畫](../../../previews/cursor-click.gif)，再在目前專案中重現它的動作節奏。不要複製範例畫面的產品名稱、文字、配色或版面；請使用目前專案的真實 UI 與品牌風格。

找出一個即將被操作、且原始素材沒有清楚游標的目標元件。讓游標以參考動畫相同的克制 ease-out 節奏移向它；在抵達時短暫縮小，接著回復，並產生一次由小到大、淡出的點擊圓環。將游標、點擊位置、進退場時間與可讀性依目前場景長度和目標位置自動調整。若原始錄影已有清楚游標或互動，不要疊加第二個游標。完成後驗證游標沒有遮住關鍵內容，且視覺點擊與任何既有點擊音效同步。
